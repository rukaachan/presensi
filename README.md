# SmartPresensi

SmartPresensi is a trustworthy photo-evidence attendance platform for schools. It brings daily attendance, class operations, student support, and administrative oversight into one role-aware workspace.

## What the app provides

- Secure daily check-in with photo evidence.
- Optional break and check-out events that never replace the required daily check-in.
- Role-based attendance workflows for students, class officers, teachers, counselors, and administrators.
- Attendance review, correction, leave requests, and status history.
- Private evidence storage served only after authorization.
- Append-only audit history for important attendance and administrative changes.
- Responsive, accessible workspaces with Indonesian user-facing content.

## Workspaces

| Role               | Primary responsibilities                                                     |
| ------------------ | ---------------------------------------------------------------------------- |
| Student            | Submit personal attendance and review personal history.                      |
| Class officer      | Record assigned-class attendance and suggest optional events.                |
| Homeroom teacher   | Monitor the assigned classroom, students, and class officers.                |
| Duty teacher       | Review attendance, correct exceptions, and oversee school operations.        |
| Counseling teacher | Review attendance patterns for timely student support.                       |
| Administrator      | Manage accounts, staff, classrooms, students, attendance, and audit history. |

## Attendance trust model

Every student has one required `daily_check_in`. Optional sessions such as `break_1`, `break_2`, and `break_3` provide additional observations without turning a missing optional event into an absence. Attendance decisions preserve evidence, authorization boundaries, and an auditable history.
